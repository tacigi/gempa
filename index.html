Sumber Data

Situs ini menampilkan data kebencanaan secara langsung dari sumber-sumber publik berikut, tanpa modifikasi nilai ilmiah:

Gempabumi & Tsunami

  • BMKG: autogempa.json, gempaterkini.json, gempadirasakan.json
  • USGS Earthquake API: pelengkap M2.0+ dengan CORS langsung

Gunung Api

  • Smithsonian GVP: database publik referensi global (nama, koordinat, klasifikasi)
  • NASA EONET v3: deteksi erupsi gunung berapi via satelit
  • MAGMA Indonesia (PVMBG/ESDM): status resmi Level I–IV — ditautkan langsung

Gerakan Tanah, Longsor, Bencana Lain

  • NASA EONET v3: deteksi satelit tanah longsor, gerakan tanah, kebakaran hutan, badai, kekeringan
  • PetaBencana.id: laporan warga terverifikasi untuk banjir, kebakaran, kabut asap, angin kencang
  • USGS Landslide Hazards: data referensi longsor global (pelengkap)

Sesuai ketentuan penggunaan data terbuka BMKG, BMKG dicantumkan sebagai sumber data resmi. Data gunung api bersifat referensi dari GVP; status Level I–IV harus diverifikasi langsung ke MAGMA Indonesia.
